- Build text, charts and simple diagrams as editable vector objects. Prefer sharp vector graphics in the exported PDF, with raster images at approximately 300 dpi at their final printed size.

### Production-only financial calculation

Keep these calculations in the source brief, not as additional printed prose. With N = 1,000, margin M = 300,000 VND, care cost c = 10,000 VND and overhead F = 10,000,000 VND:

- Total incremental cost C = N × c + F = **20,000,000 VND**.
- Net value = N × incremental retained fraction × M − C.
- Low: 1,000 × 0.02 × 300,000 − 20,000,000 = **−14,000,000 VND**; ROI = **−70%**.
- Base: 1,000 × 0.05 × 300,000 − 20,000,000 = **−5,000,000 VND**; ROI = **−25%**.
- High: 1,000 × 0.08 × 300,000 − 20,000,000 = **+4,000,000 VND**; ROI = **+20%**.
- Break-even retained fraction = C / (N × M) = 0.066667 = **6.67 percentage points**.

The amount is contribution margin, not gross revenue or an unlimited customer lifetime value. These numbers already appear in the deck content and are retained for consistency, not because a pilot has verified them.
